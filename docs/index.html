小镇玩法 为什么开源 参与共建

一座小镇，大家一起建。

我们从直播版已有的小镇中抽出可公开的表现层。熟悉的地图、四季天气、镇民动作和建造画面，都是大家可以接着优化的地方。

看怎么参与共建 先逛逛小镇

你专注，镇民开工。

独立专注版提供本地番茄钟。开钟后，20 位通用镇民分头伐木、种田和施工。每轮完成的专注都会推进建造，休息时也可以拖动地图看看镇民去哪儿了。

为什么开放
直播版的表现层？

看直播时，有人会注意到雨中的路面不够清楚，或镇民转身时动作接得太急。把直播版可公开的画面整理成独立 Godot 工程，大家就能在同一处机位复现问题、试改一版，再把前后效果拿给其他人看。

仓库里的 AGENTS.md 和扩展 Skill 会指出该看哪个文件、改完去哪里看效果。你可以自己动手，也可以让 Agent 读着手册，陪你做第一个改动。

从试玩里发现问题

看到夜里工地太暗，记下机位、天气和时段，别人就能在同一处复现。

给小镇添一点画面

把伐木的动作接顺，给休息的小人添个打盹动作，或调整施工时的屋顶和围挡。

动手改一处工程

打磨镜头移动、雨后反光和人多时的帧率。提交时带上同机位的画面对照。

从你想改的一处开始。

GitHub 承接源码、画面反馈和改动评审。经过复看和确认的改进可以回到直播版，让观众也看到这份贡献。

打开 GitHub 仓库

正式开源版本、源码许可证和素材授权随项目发布说明。

  1. 先跑一轮

    按 README 在 Windows 用 Godot 打开项目，开一轮番茄钟，看看镇民平时怎么工作和休息。

  2. 找到你想改的地方

    从贡献者指南定位入口。第一次可以只改一个动作、一种天气效果或一张建筑图。

  3. 把改动带回 GitHub

    发现问题就发 Issue，有实现就提 Pull Request。带一张对照图或一段短录屏，大家可以跟着复看。
