鲸鲸小镇
小镇玩法 为什么开源 参与共建

一座小镇，大家一起建。

开一轮番茄钟，20 位镇民就去伐木、种田和施工。你休息，他们也散开走走。我们准备开放这座海边小镇的基础工程，让大家从同一份可玩的专注版开始共建。

看怎么参与共建 先逛逛小镇

你专注，镇民开工。

完成一轮专注，时间就会变成建造进度。你可以拖动地图去看看林地、农田和工地。日夜和四季跟着本机时钟走，天气也在镇上自己变化。

为什么开放
小镇的基础工程？

想给镇民加一个休息动作，先得有个跑得起来的小镇。我们把地图、环境、人物动作、建造和本地番茄钟放在同一个 Godot 工程里。大家可以从现成的画面开始改，也能在同一座镇里试试彼此的作品。

仓库里的 AGENTS.md 和扩展 Skill 会指出该看哪个文件、改完去哪里看效果。你可以自己动手，也可以让 Agent 读着手册，陪你做第一个改动。

从试玩里发现问题

拖到工地看一轮开工。要是发现镇民挡住了路，把机位和当时在做什么记下来。

给小镇添一点画面

画一个新屋顶，做个打盹动作，或试试雪落下来时，窗边该亮什么颜色。

动手改一处工程

调一段工人路线，或者给雨停后的路面添一点水光，再用晴雨对照跑一遍。

从你想改的一处开始。

GitHub 保存源码、建议和每次改动的讨论。后来的人可以沿着这些记录复现效果，接着把小镇往前建。

打开 GitHub 仓库

仓库目前用于私有审阅，正式开放以项目发布为准。

  1. 先跑一轮

    按 README 在 Windows 用 Godot 打开项目，开一轮番茄钟，看看镇民平时怎么工作和休息。

  2. 找到你想改的地方

    从贡献者指南定位入口。第一次可以只改一个动作、一种天气效果或一张建筑图。

  3. 把改动带回 GitHub

    发现问题就发 Issue，有实现就提 Pull Request。带一张对照图或一段短录屏，大家可以跟着复看。
