# 鲸鲸小镇 · 专注版

鲸鲸小镇是一座会陪你专注的海边小镇。你开钟，20 位镇民各自去伐木、种田和施工。你休息，他们就散开走走。每轮完成的专注都用来建设小镇。

我们希望和大家一起把小镇建得更好。这份独立工程开放最基础的地图、天气、动作和建造表现作为共建底座。你可以从一个小改动开始，比如给镇民添一个休息动作、做一阵秋风，或画一座更好看的林间小屋。

## 参与共建

介绍站面向第一次认识小镇的人，讲清项目做什么、怎样试玩、可以从哪里参与。GitHub 将承载源码、建议和改动评审，方便大家一起积累作品和维护经验。

修改前可先看 [给贡献者和 Agent 的入口](AGENTS.md) 和 [人物动作、天气和建造扩展 Skill](.agents/skills/whale-focus-visuals/SKILL.md)。带上改动前后的截图或一段短录屏，其他人就能用同一个机位复看。如果新增素材，请在 [素材清单](art/asset-license.json) 旁标明作者、来源和授权状态。

## Windows 启动

1. 将 ZIP 完整解压到可写的本机目录。
2. 准备标准版 Godot 4.4 或以上。把 Windows Godot 主程序复制到解压目录并命名为 `Godot.exe`，与 `Start-Focus.cmd` 放在一起。
3. 双击 `Start-Focus.cmd`。脚本先导入素材，再打开小镇窗口。

已经装有 Godot 时，也可以在项目管理器中导入解压后的 `project.godot`，打开后按 F5。命令行可设置 `GODOT_EXE` 为现有 Godot 主程序的完整路径，再运行启动脚本。

源码包需要本机 Godot。导入和游玩均可离线进行。Windows 默认存档为 `%APPDATA%\Godot\app_userdata\鲸鲸小镇 · 专注版\focus-town.json`，更新源码时沿用。并排试玩两个版本时，为验收进程设置独立的 `APPDATA`。

其他平台可从项目目录运行以下命令。

```sh
godot --headless --path . --import
godot --path .
```

用鼠标拖动地图或在触屏上滑动查看小人，番茄钟始终在屏幕下方。开钟后，20 个通用小人分成 6 个伐木、6 个种田、8 个施工。暂停或结束后，他们放下工具，散到路边和岸上休息。

番茄钟可选 15、25 或 45 分钟。整轮到时记入建设，提前结束会取消本轮。暂停时冻结剩余时间，重新打开后可继续。运行中关闭游戏时，本机计时继续走，重开到点后结算一次。关闭前可先暂停。

镇民中心需要 30 小时、林间小屋需要 60 小时、晚风舞台需要 110 小时。各阶段累计在 30、90、200 小时完成，等于 480 轮默认专注。已有存档的已完成分钟数会带入当前门槛。三座建筑落成后，开钟仍会派 8 人到晚风舞台维护。

四季、晨昏和夜晚跟随本机日期与时间。随机天气按本地时段选取，同一时段重开时续接对应的天气。雨会渐起渐停，路面随后慢慢变干。
